Smart Museum IoT Environmental Monitoring

Date Jul 2025 (Updated)
Category IoT Full-Stack
Status Completed
Python Node-RED TelosB nesC TinyOS Firebase

Overview

Full-stack environmental monitoring system for Smart Museums, leveraging physical sensors to collect, route, and visualize critical telemetry data.

Technical Implementation

The architecture is powered by TelosB sensors running nesC/TinyOS. At the edge, a Python programming interface was developed for local data processing and immediate display. Processed data is then routed seamlessly via Node-RED into a cloud-hosted Firebase architecture.
